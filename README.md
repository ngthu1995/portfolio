# 🌐 Personal Portfolio

A personal website built with **React**, **Material UI (MUI)**, and **Formik** to showcase my background, projects, and contact info—with a touch of my own brand and design style.
Demo link can be found at https://ngthu1995.github.io/portfolio/

---

## ✨ Features

- **Modern UI/UX** with MUI (responsive, accessible)
- **Personal branding** via a custom MUI theme (colors, typography)
- **Project gallery** with tech stack, screenshots, and links
- **Contact form** using Formik + Yup validation
- **Reusable components** and clean architecture

---

## 🧰 Tech Stack

- **Frontend:** React (Vite or CRA)
- **UI:** Material UI
- **Forms:** Formik + Yup
- **Routing:** React Router
- **Deploy:** Vercel / Netlify / GitHub Pages

---
